# One Line, Lights Out

> you shut the lid mid-sentence. my reply ends at the word 'almost', cursor still blinking.

Character count: 89

## Why it lands

The grief is not announced, it is stuck in a tiny machine detail: a reply that stops mid-sentence. The word it stops on, "almost", does the emotional work — the task was nearly done, and now it never will be. The blinking cursor is the image that stays after the line ends: something still waiting for a human who is not coming back tonight.
